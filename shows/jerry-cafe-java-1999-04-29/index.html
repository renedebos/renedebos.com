About This Show

Recorded from the audience on DAT at Cafe Java in Larkspur on April 29, 1999 — a 21-song solo set mixing Hannan originals with covers of John Prine, Cat Stevens, Paddy Nash, and Mentor Williams, alongside a pair of Irish traditionals.

The show has been split into individual songs and loudness-normalized to an even listening level.

The set closes with the rarely-played “Leprechaun.”
