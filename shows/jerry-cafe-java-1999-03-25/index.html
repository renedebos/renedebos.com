About This Show

Recorded from the audience on DAT at Cafe Java in Larkspur on March 25, 1999 — a 21-song solo set of Hannan originals with covers of John Prine and Paddy Nash, plus a pair of Irish traditionals. Kelly Peterson joins Jerry for “Daddy.”

This tape also holds a second date (April 8, 1999), split out as its own show.
